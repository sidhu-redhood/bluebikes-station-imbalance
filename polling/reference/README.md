# Reference data

## boston_neighborhoods.geojson

Neighborhood boundaries for the City of Boston. We use them to tag each Bluebikes station with a neighborhood.

**Source:** Boston Neighborhood Boundaries, published on Analyze Boston by Boston Maps.
Dataset page: https://data.boston.gov/dataset/bpda-neighborhood-boundaries

**License:** Open Data Commons Public Domain Dedication and License (PDDL). We can reuse and redistribute it.

**Downloaded:** Oct 26, 2026 (the dataset page listed it as last modified Oct 15, 2026)

**Format:** GeoJSON FeatureCollection with 26 features. Each feature is a `Polygon` or a `MultiPolygon`. Coordinates are `[longitude, latitude]`.

**Field we use:** `properties.name` holds the neighborhood name, for example `Fenway` or `Back Bay`.

### Things to know

- These are not official city boundaries. The publisher says they combine zoning neighborhood boundaries, zip code boundaries and 2010 census tracts. Treat them as good for analysis, not as legal lines.
- Kenmore is not its own neighborhood in this file. It is part of `Fenway`.
- Longwood is its own neighborhood. It sits between Mission Hill and Fenway.
- The file covers Boston only. Stations in Cambridge, Brookline, Somerville and other towns will not match any polygon, so they get no neighborhood. That is expected.
- Stations close to a boundary can land on the wrong side. The tagging script lists these so we can check them by hand.

### How it is used

The tagging script reads this file, checks which polygon contains each station's `lon` and `lat`, and writes the result to the `station_neighborhoods` table. The raw station data is never changed, so we can swap this file for another boundary set later without touching anything else.

Do not edit this file by hand. If we need a different set of boundaries, add a new file next to it and note the source here.
